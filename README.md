# Sport Portfolio

A modern sports portfolio web app to showcase your information, photos, training and gameplay videos, statistics, and coach testimonials. Includes features to upload new content and allow comments.

## Structure
- `frontend/`: HTML, CSS, JS files
- `backend/`: Node.js Express server
- `uploads/`: Media storage

## How to Run
1. Install backend dependencies:
   ```powershell
   cd backend
   npm install
   ```
2. Start the backend server:
   ```powershell
   node server.js
   ```
3. Open `frontend/index.html` in your browser.

## Features
- Upload photos/videos (to be implemented)
- Add/view comments
- Display statistics and testimonials
